# Digital Image Processing - Interactive Lab Module

This repository contains an interactive Jupyter Notebook designed to teach the fundamentals of Digital Image Processing. It transitions from basic mathematical pixel operations to advanced frequency-domain filtering, providing visual, interactive proof of how these algorithms manipulate images.

---

## 🛠 Dependencies & Requirements

This module is built for **Python 3.11** and relies on industry-standard computer vision and data science libraries. 

To run the interactive cells and process the images, you will need the following packages:
*   **Jupyter Notebook:** To run the `.ipynb` interactive environment.
*   **OpenCV (`opencv-python`):** For optimized, C++ backed image processing algorithms.
*   **NumPy (`numpy`):** For matrix mathematics and manual algorithm implementation.
*   **Matplotlib (`matplotlib`):** For rendering images, displaying histograms, and plotting results.
*   **IPyWidgets (`ipywidgets`):** To generate the interactive sliders and checkboxes directly inside the notebook cells.

### Installation
You can install all required dependencies at once using pip. Open your terminal or command prompt and run:

```bash
pip install notebook opencv-python numpy matplotlib ipywidgets
